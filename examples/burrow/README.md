# burrow

burrow is a fictional TypeScript monorepo shaped like a fenced codebase, made up so the platform has a project to show a ratchet and a migration split six ways on; its maintainers are fictional too. It is a Bun project of its own, not a workspace of this repo: the root's workspaces, lint, format and typecheck leave it out, and it lints and tests with its own config. Issue 508 fills it in.
